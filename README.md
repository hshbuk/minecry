# FarSight: World Discovery (Fabric 1.21.1)

מוד למיינקראפט (Fabric 1.21.1) המכניס את מכניקת גילוי העולם של **Far Cry**:

## פיצ'רים עיקריים
1. **מגדלי פילג'רים מותאמי ביומים (6 ערכות נושא)**:
   - Plains / Forest, Desert, Snowy / Taiga, Jungle, Badlands / Mesa, Swamp / Mangrove.
   - כל מגדל כולל 4 קומות + גג, שומרי Pillager ו-Vindicator, תיבת שלל, ו-2 **ממסרי תדר (`Signal Relay`)** שחוסמים את מחסום האבטחה (`Tower Barrier`) לגג.
2. **פאזלים כפולים בכל מגדל**:
   - **פאזל פיזי בתוך המגדל**: כוונון ממסרי התדר (`Signal Relay`) בקומות המגדל כדי לפתוח את מחסום הגג.
   - **פאזל מסוף בגג (`Tower Signal Terminal`)**: לאחר חיסול השומרים וכוונון הממסרים, אינטראקציה עם המסוף פותחת פאזל סנכרון מעגלים (`IN -> OUT`).
3. **פתיחת אזור וגילוי אוטומטי של אתרים מיוחדים**:
   - הפעלת המגדל חושפת אזור ברדיוס 512 בלוקים (`1024x1024`) וסורקת אוטומטית כפרים, מקדשים, Outposts, Trial Chambers, Ancient Cities, Ruined Portals, Strongholds, Mineshafts, מערות מיוחדות (Lush Caves / Deep Dark) ואת המגדל הבא באופק.
4. **מפה אינטראקטיבית, מצפן עליון ועמודי אור בעולם**:
   - **מקש `M`**: פתיחת מפת העולם עם ערפל מלחמה (Fog of War), גבולות אזורים, אייקוני אתרים, זום וגרירה, ובחירת יעד (Waypoint).
   - **מצפן HUD עליון**: מציג כיוונים (`N/E/S/W`), אייקונים קרובים ומרחק ליעד.
   - **עמודי אור בתלת-ממד**: עמודי אור זוהרים בעולם מעל אתרים שהתגלו ומעל ה-Waypoint הפעיל.
   - **משקפת סיור (`Scout Binoculars`)**: סריקה מרחוק של מגדלי פילג'רים באופק.

## בנייה והרצה (Build & Run)
נדרש **Java 21 (JDK 21)** ו-Gradle (או Gradle Wrapper):
```bash
gradle build
```
הקובץ `.jar` ייווצר בתיקייה `build/libs/`.
להרצה ישירה לבדיקה:
```bash
gradle runClient
```
פקודת בדיקה במשחק (עם הרשאות אופרטור):
- `/farsight spawn_tower` — מזמן מגדל פילג'רים מותאם לביום הנוכחי לידך.
- `/farsight info` — מציג כמה אזורים ואתרים נחשפו.
